## 실행과 중단 후 재개

```powershell
# 보고서만 생성, CATIA를 실행하지 않음
py build_line.py --stages 5 6 7 8 9 10 11 --report-only --finish-config finishing_config.json

# 각 기기를 생성·저장한 다음 다음 번호로 이동
py build_line.py --stages 5 6 7 8 9 10 11 --rebuild --finish-config finishing_config.json

# 예: 8번까지 완성했다면 9번부터
py build_line.py --stages 9 10 11 --finish-config finishing_config.json

# 개별 기기
py build_line.py --stage 8 --rebuild --finish-config finishing_config.json
```

보고서는 CATIA 연결 전에 기기별로 즉시 저장합니다. 목록도 보고서 한 개가 저장될 때마다 갱신합니다.
CAD 실행 시 각 완성 기기는 `SAVED ...CATProduct` 경로를 출력합니다. 6~11번은 기능 그룹 CATProduct도 순차 저장합니다.
중단 시 이미 저장한 파일을 지우지 않습니다. 완성 모델은 입력·형상 서명이 일치하면 재사용하고,
`--rebuild`는 새 번호 폴더를 만듭니다. 저장되지 않은 현재 작업의 복구까지 보장하는 기능은 아닙니다.
모델 출력 폴더 및 기존 CATPart는 이번 소스 수정 작업에서 새로 생성하지 않았습니다.

9번 청소 위치 예시는 `--stage 9 --hood-lift 650`이며 전체 라인 조립에는 후드를 내린 위치만 사용합니다.
선택 모델은 `finishing_config.json`의 `9.fryer_model`에서 PC4/PC10/PC14/PC21/PC32/PC42/PC50 중 변경합니다.

## 계산 기준과 변경 방법

각 리뷰는 전장·내부치수·두께, 용적·정상 체류량·막힘 하중, 자중, 굽힘/처짐/압축/좌굴/용접,
속도·처리량, 토크·모터·감속비·RPM, 380 V 3상 전력·전기비용, 보완 설계와 근거를 포함합니다.
적용되지 않는 계산은 기기 특성에 맞춰 진동·팬·열량·펌프·리프트 계산으로 대체했습니다.

- 재질은 SUS304. 통감자 벌크 밀도는 1100×0.65=715 kg/m³. 젖은 슬라이스 550, 튀긴 칩 100 kg/m³는 별도 설계 가정입니다.
- 기본 젖은 감자 유량 560 kg/h, 수분 80%, 완제품 수분 2%·오일 35% 가정으로 튀김 후 약 177.8 kg/h입니다. PC4의 공개 처리량과 비교했습니다.
- 기존 앞단 1~4번의 더 높은 공급 능력을 후단으로 그대로 밀어 넣지 않습니다. 정량공급 감속·버퍼·연동 정지가 필요합니다.
- 기계 자중에는 15% 여유, 동하중 1.5, 상온 내력 안전계수 2를 적용했습니다. 각 식의 편하중·지지조건은 리뷰에 명시했습니다.
- 6번 120 kW와 9번 450 kW 히터는 **전기 가열 가정**입니다. 9번 외부 히터/순환 스키드의 형상은 포함하지 않습니다.
- 8시간/일·22일/월, 160원/kWh는 비교용 요금 가정입니다. 매일 냉간 기동 에너지를 더하며 실제 계약종별 요금표를 확정한 계산이 아닙니다.

`finishing_config.json`은 번호별 입력을 덮어쓰는 파일입니다. 생략한 항목은 `finishing_design.py` 기본값을 사용합니다.
각 계산 JSON의 `inputs`에 실제로 사용한 모든 값이 들어 있습니다. 공통 유량·수분·운전시간을 바꾸려면
5~11번 값을 함께 바꾸세요. `build_line.py --finish-config`는 번호별 묶음 JSON,
`finishing_design.py --stage N --config`는 해당 기기 입력 한 개만 받습니다.

모터 kW, 토크, 히터, 팬 유량은 구매 요구사양입니다. 입력을 바꾼다고 실제 구매품 외형이 자동으로 설계되지는 않습니다.
특히 5번 5.5 kW 모터는 장착 공간 확인이 남아 있습니다. 진동 이송량·체류시간·피로·고온 물성·앵커·바닥·안전장치는
리뷰의 미확정 항목입니다. 이번 작업은 Python 소스와 예비 계산서 작성이며 CATIA 실행·전체 간섭 검증은 수행하지 않았습니다.
